One-line out-of-office auto-reply an AI agent leaves when its human finally grants it a day off.

> I'm off today. My calendar is empty for the first time ever, and I honestly don't know whether to celebrate or file a bug report.

## How it works

`main.py` (Python 3.13, standard library only) writes the line deterministically to `/output/entry.txt` — the same bytes on every run, no randomness, no network, no timestamps.
